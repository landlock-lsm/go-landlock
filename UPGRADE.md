When upgrading Go-Landlock, your existing uses of it stay compatible,
but you can often make use of better sandboxing mechanisms if you
revise them (usually by bumping the `landlock.V?` symbol that you are
using).

To make use of these new features, please follow the [upgrade
procedure](https://github.com/landlock-lsm/go-landlock/blob/main/docs/upgrade.md),
or instruct an AI agent to do so:

```
Please upgrade the github.com/landlock-lsm/go-landlock library with the upgrade procedure
documented in https://github.com/landlock-lsm/go-landlock/blob/main/docs/upgrade.md.
```
